# Amp

Pulpit studia. Kolory całego interfejsu pochodzą z aktywnego motywu, a każdy motyw jest oparty na palecie z [Color Hunt](https://colorhunt.co/).

## Uruchomienie

```bash
npm install
npm run dev
```

Motyw wybiera się na pulpicie albo na stronie Motywy. Wybór zostaje w przeglądarce.
